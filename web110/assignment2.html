There are different ways to fix broken links.I have never heard of this before, so I found it interesting to learn why a link might not work. A broken link can happen because the page no longer exists or because there is a problem with the link itself. I learned that sometimes I can fix a broken link by checking the URL, removing extra punctuation, or correcting mistakes in the web address. I can also copy and paste the URL instead of clicking the link. Another thing I learned is that if a specific page does not work, I can delete everything after the domain name and try going to the website’s main page. If that does not work, I can search for the page using a Web browser or ask the person who sent the link to resend it. This knowledge is important to me as a student because it will help me make sure that the links are properly working when I am creating websites. Clearing your cache is one of the important activities that I have enjoyed. I learned that a web browser cache saves things like images, text, and other information from websites that I visit. It helps websites load faster when I visit them again. However, I also learned that sometimes the cache can cause problems, especially when a website has been updated but my browser still shows the old version. Clearing the cache can fix this by making the browser load the newest version of the website. As a student and future developer, I believe this will be a useful thing when I am creating and testing websites. If I make changes to my website and cannot see them, I will know that the browser cache might be the reason. I can clear it and check if my changes appear correctly. Lastly, I learned that web browsers have different settings that can change the way we use the Internet. Before this lesson, I did not know that web browsers such as Chrome, Brave, Edge, Firefox, Opera, and Safari have their own settings and advanced options. I learned that I could change these settings to improve my browsing experience and make the browser work better for my needs. There is a help center for each browser when I do not understand a setting or need help changing something. For example, a website may not display correctly, or certain features may not work. To solve this, I would open the browser’s settings and check the privacy, security, and site settings. I could also check my extensions and disable any that might be causing the problem. If I still cannot fix it, I would use the browser’s help center to find the correct solution. Another thing I learned is not every browser does not have the same browser settings, so it is a must to know where to find them. This knowledge could improve myself to be more aware on how to identify things and issues that I can solve right away as a student a future Web Developer.
