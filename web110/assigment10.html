After reviewing the CSS lessons and tutorials, I learned how important CSS is when creating a website. Before this activity, I understood that HTML is used to build the structure of a webpage, but I did not fully understand how CSS controls its appearance. I learned that CSS stands for Cascading Style Sheets and is used to add colors, change fonts, adjust text sizes, and organize different parts of a webpage. I also learned about CSS selectors, properties, and values, which work together to apply specific styles to HTML elements. What I found interesting is that even a simple webpage can look completely different just by changing a few CSS properties. This activity helped me understand that a good website is not only about making sure everything works but also about making the design easy for visitors to understand and navigate.

I also learned how to apply inline CSS directly to HTML elements using the style attribute. I found this method easy to understand because I could see the changes immediately after adding styles to an element. For example, I could change the color of a heading, adjust the font size of a paragraph, or add a background color to a specific section of a webpage. I also learned how to use text-align and font-family to change how text looks. However, I realized that inline CSS can make HTML code longer, especially when there are many elements that need styling. Even though it is useful for making quick changes to individual elements, it may not be the best option for larger websites.

Furthermore, I learned how internal CSS works by placing CSS rules inside the style element in the head section of an HTML document. Compared to inline CSS, I think internal CSS is more organized because I can apply styles to multiple elements without adding the same code repeatedly. For example, I can change the appearance of all headings or paragraphs using one rule. This makes it easier to maintain a consistent design throughout a single webpage. I also learned the importance of using the W3C HTML Validator to check my webpage for errors. This activity helped me understand that writing code is not just about getting the design I want but also making sure the code is properly written.

Lastly, I learned how to create an external CSS file and connect it to an HTML document. I think this method is especially useful when working on websites with multiple pages because one stylesheet can control the design of several webpages. I also learned about properties such as margin, padding, width, border, and float. These properties help control the spacing, size, and positioning of different elements. What I liked about external CSS is that I can make changes in one file instead of editing every HTML page individually. I also learned how to use the W3C CSS Validator to check for errors and make corrections. This helped me understand why keeping code organized is important when building a website. Overall, these activities helped me understand how HTML and CSS work together in web development. I still need more practice, especially with positioning elements and creating different layouts, but I feel more comfortable with the basics now. I believe these skills will help me as I continue learning web development and creating my own websites in the future.
