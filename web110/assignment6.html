From studying screen sharing and remote desktop applications, I learned how technology makes it possible to access and assist another computer even when people are in different locations. I learned that applications such as Chrome Remote Desktop, Quick Assist, and Virtual Network Computing (VNC) allow users to view a computer screen and, depending on the application and permission given, control the computer remotely. Chrome Remote Desktop can be used to access files and applications from another computer, while Quick Assist is useful for providing technical support by allowing someone to view or control a device with the user's permission. VNC also allows a computer's screen, keyboard, and mouse inputs to be shared over a network. I realized that these technologies can be very helpful when someone needs technical assistance without being physically present. As a future web developer, I also see how remote access can make teamwork, troubleshooting, and technical support more convenient. This lesson helped me appreciate how remote technologies connect people and make solving computer-related problems easier. Using remote desktop technology I am capable of helping classmates or teammates with technical problems. As a future web developer, I can apply this knowledge when troubleshooting projects, providing support, or working with teammates remotely while always making sure that access is authorized and secure.
